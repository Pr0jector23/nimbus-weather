# Nibus Weather App

A simple weather viewing app made using React JS, Next.JS and Tailwind CSS.

## Overview
**The app is capable of the following things:**
- Selecting the area you want to see the weather for using a search bar
- Weather for today
- Weather for the next 5 days
- Advanced weather features like visibility and humidity
- A weather graph showing the temperature changes
- A weather map with 4 modes: temperature, percipitation, wind and clouds

## Libraries and APIs used
The weather API was provided by [Open Weather Map](https://openweathermap.org/)
The weather map was provided by [Leaflet](https://leafletjs.com/)
